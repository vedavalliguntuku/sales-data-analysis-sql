# Sales Data Analysis Using SQL

## Project Overview

This project analyzes sales transaction data using MySQL to identify
sales trends, customer behavior, product performance, revenue patterns,
and purchasing behavior.

## Tools Used

- MySQL
- SQL
- GitHub

## Data Cleaning

- Converted purchase date into DATE format
- Converted purchase time into TIME format
- Standardized data types
- Prepared the dataset for analysis

## Business Questions

1. What are the top 5 best-selling products?
2. Which products are most frequently cancelled?
3. What time of day has the highest number of purchases?
4. Who are the top 5 highest-spending customers?
5. Which product categories generate the highest revenue?
6. What is the return/cancellation rate by category?
7. What is the preferred payment mode?
8. How does age group affect purchasing behavior?
9. What is the monthly sales trend?
10. Are certain genders buying specific product categories?
